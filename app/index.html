Login

Autentique-se para obter o Bearer token necessário em rotas protegidas.

Listar usuários

Filtre por qualquer campo ou deixe em branco para listar todos.

Criar usuário

Cadastra um novo usuário. Não é necessário token.

Buscar usuário por ID

Retorna um único usuário pelo seu _id.

Editar usuário

Atualiza os dados de um usuário. Requer token de admin.

Excluir usuário

Remove um usuário pelo ID. Requer token.

Listar produtos

Filtre por qualquer campo ou deixe em branco para listar todos.

Criar produto

Cria um produto. Requer token de admin.

Buscar produto por ID

Retorna um único produto pelo seu _id.

Editar produto

Atualiza os dados de um produto. Requer token de admin.

Excluir produto

Remove um produto pelo ID. Requer token de admin.

Listar carrinhos

Filtre por qualquer campo ou deixe em branco para listar todos.

Criar carrinho

Cria um carrinho para o usuário autenticado. Requer token.

Buscar carrinho por ID

Retorna um único carrinho pelo seu _id.

Concluir compra

Finaliza o carrinho do usuário autenticado, atualizando o estoque. Requer token.

O carrinho é identificado automaticamente pelo token. Não há parâmetros adicionais.

Cancelar compra

Cancela o carrinho e devolve os produtos ao estoque. Requer token.

O carrinho é identificado automaticamente pelo token. Não há parâmetros adicionais.
